# Lab Assignment 4: Error Detection and Correction

---

## Description

This assignment demonstrates the concept of error detection and correction using block coding and Cyclic Redundancy Check (CRC). A simple network is simulated to visualize data transmission and understand how errors are handled conceptually.

---

## Steps to Perform the Experiment

1. Create a network with:

   * 2 PCs
   * 1 Switch

2. Connect both PCs to the switch

3. Assign IP addresses:

   * PC1 → 192.168.50.1
   * PC2 → 192.168.50.2

4. Switch to Simulation Mode

5. Send packets using Add Simple PDU

6. Observe packet flow

7. Add notes explaining:

   * Block Coding
   * CRC

---

## Learnings

* Error detection ensures reliable communication
* Block coding uses parity bits for error checking
* CRC is a powerful error detection method
* Errors may occur during transmission
* Simulation helps visualize data flow
