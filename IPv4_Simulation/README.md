# Lab Assignment 8: IPv4/IPv6 Addressing and Address Mapping

---

## Description

This assignment demonstrates logical addressing using IPv4 and IPv6 along with address mapping techniques such as ARP, RARP, BOOTP, and DHCP using Cisco Packet Tracer. The process of IP address allocation and resolution is observed through simulation.

---

## Steps to Perform the Experiment

1. Create a network with:

   * 2 PCs
   * 1 Switch
   * 1 Server

2. Connect all devices

3. Configure DHCP on Server:

   * Enable DHCP service
   * Define IP pool

4. Configure PCs:

   * Set IP configuration to DHCP
   * Obtain IP addresses automatically

5. Switch to Simulation Mode

6. Send packet from PC1 to PC2

7. Observe:

   * ARP request and reply
   * ICMP communication

8. Add notes explaining:

   * RARP
   * BOOTP

---

## Learnings

* DHCP dynamically assigns IP addresses
* ARP resolves IP address to MAC address
* RARP resolves MAC to IP (conceptual)
* BOOTP provides boot-time configuration
