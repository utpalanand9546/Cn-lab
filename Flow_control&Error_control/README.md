# Lab Assignment 5: Flow Control and Error Control Protocols

---

## Description

This assignment demonstrates flow control and error control mechanisms including Stop and Wait, Go-Back-N, and Selective Repeat protocols using Cisco Packet Tracer. The behavior of packet transmission is observed using simulation mode.

---

## Steps to Perform the Experiment

1. Create a network with:

   * 2 PCs
   * 1 Switch

2. Connect both PCs

3. Assign IP addresses:

   * PC1 → 192.168.60.1
   * PC2 → 192.168.60.2

4. Switch to Simulation Mode

5. Simulate Stop and Wait:

   * Send one packet at a time

6. Simulate Go-Back-N:

   * Send multiple packets

7. Simulate Selective Repeat:

   * Observe packet behavior

8. Add notes explaining each protocol

---

## Learnings

* Stop and Wait sends one packet at a time
* Go-Back-N sends multiple packets but retransmits from error point
* Selective Repeat retransmits only erroneous packets
* Flow control ensures efficient transmission
* Error control improves reliability
