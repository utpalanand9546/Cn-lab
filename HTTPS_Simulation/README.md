# Lab Assignment 11: HTTP and Web Server Simulation

---

## Description

This assignment demonstrates the working of HTTP protocol and web server communication using Cisco Packet Tracer. A simple web page is hosted on a server and accessed by client devices.

---

## Steps to Perform the Experiment

1. Create a network with:

   * 1 Server
   * 2 PCs
   * 1 Switch

2. Connect all devices

3. Configure server:

   * Assign IP address
   * Enable HTTP service
   * Edit index.html

4. Configure PCs with IP addresses

5. Test connectivity using ping

6. Open web browser on PC

   * Enter server IP address

7. Observe HTTP request and response using Simulation Mode

---

## Learnings

* HTTP is used for web communication
* TCP ensures reliable data transfer
* Web server responds to client requests
* HTTP follows request-response model
* Simulation helps visualize protocol behavior
