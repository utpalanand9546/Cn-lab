# Lab Assignment 3: Network Simulation for Delay and Packet Analysis

---

## Description

This assignment demonstrates packet transmission between networks using a router. It focuses on analyzing packet delay, packet flow, and communication behavior using Simulation Mode in Cisco Packet Tracer.

---

## Steps to Perform the Experiment

1. Create a network with:

   * 2 PCs
   * 2 Switches
   * 1 Router

2. Connect devices:

   * PC → Switch → Router → Switch → PC

3. Configure IP addresses:

   * PC1 → 192.168.1.2
   * PC2 → 192.168.2.2

4. Configure router interfaces:

   * FastEthernet0/0 → 192.168.1.1
   * FastEthernet1/0 → 192.168.2.1

5. Set default gateways on PCs

6. Switch to Simulation Mode

7. Send packets using Add Simple PDU

8. Observe packet flow, delay, and event list

---

## Learnings

* Router enables communication between different networks
* Packet delay can be observed in Simulation Mode
* ARP and ICMP protocols are involved in communication
* Multiple packets can increase delay
* Simulation helps visualize real network behavior
