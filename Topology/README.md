# Lab Assignment 1: Network Topologies Simulation

---

## Description

This assignment demonstrates the design and simulation of different network topologies including bus, star, ring, and mesh using Cisco Packet Tracer. Each topology is analyzed based on its structure and data flow behavior.

---

## Topologies Implemented

* Bus Topology
* Star Topology
* Ring Topology
* Mesh Topology

---

## Steps to Perform the Experiment

1. Open Cisco Packet Tracer

2. For each topology:

   * Add required PCs
   * Connect devices based on topology structure
   * Assign IP addresses
   * Test connectivity using ping

3. Observe packet flow using Simulation Mode

---

## Learnings

* Bus topology uses shared communication medium
* Star topology uses centralized control (switch)
* Ring topology follows circular connection
* Mesh topology provides high redundancy
* Network efficiency and fault tolerance vary across topologies
